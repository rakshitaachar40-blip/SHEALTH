# SHEALTH — Application Screenshots

This directory is intended to contain screenshots of the actual SHEALTH application.

Screenshots help reviewers understand the interface and follow the user journey without needing to run the project immediately.

## Planned Screenshots

1. Home dashboard
2. Symptom tracker
3. Health insights
4. Women's health education
5. Doctor support and health-report generation
6. SHEALTH Connect prototype, if successfully integrated

## Screenshot Guidelines

* Use screenshots captured from the running application.
* Use fictional test data.
* Do not include passwords, API keys, or confidential information.
* Do not expose real users' medical records or other personal information.
* Label prototype functionality accurately.

Screenshots will be added after the corresponding application pages have been tested.
